# SIH-RuralEdge-AI

## 🌾 RuralEdge AI

SIH-RuralEdge-AI is a smart AI-powered platform designed to support rural communities by providing financial guidance, government scheme information, feasibility analysis, and intelligent advisory services.

## 🚀 Features

- AI-powered rural financial advisory
- Financial feasibility analysis
- Government scheme information
- Gemini AI advisory
- Geo-location based services
- Multi-language support
- Voice-based advisory
- PDF report generation

## 🛠️ Technologies Used

### Frontend
- React
- TypeScript
- Vite
- CSS

### Backend
- Python
- FastAPI
- AI/ML services
